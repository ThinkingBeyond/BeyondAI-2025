# BeyondAI: Introduction to AI and Research 2025
This repo contains the research project submissions for the [BeyondAI programme](https://thinkingbeyond.education/beyondai/) in 2025. Apart from one maths project on the universal approximation theorem for MLPs all other projects are code based. The accompanying research posters for each project can be found in the [BeyondAI Proceedings 2025](https://thinkingbeyond.education/beyondai_proceedings_2025/).

For the individual research projects please navigate to the folder of each team. For research projects of past iterations of the *BeyondAI* programme please navigate to [BeyondAI 2024](https://github.com/ThinkingBeyond/BeyondAI-2024).
